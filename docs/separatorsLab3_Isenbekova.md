# Использование разделителей

## Введение
Markdown — простой инструмент для структурирования текстов.

---

## Основные возможности Markdown
Среди ключевых возможностей: заголовки, списки, таблицы и выделение текста.

***

## Пример форматирования
Разделы документа аккуратно отделяются друг от друга тонкими горизонтальными линиями.
