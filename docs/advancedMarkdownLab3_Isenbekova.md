## Сноски
Markdown очень полезен в процессе ведения технической документации разработчика[^markdown].

[^markdown]: Спецификация Markdown активно поддерживается GitHub, GitLab и Obsidian.

## Alert-блок GitHub
> [!TIP]
> Используйте сочетание клавиш `Ctrl + Shift + V` в VS Code, чтобы быстро открывать предпросмотр Markdown-файлов на соседней панели.
