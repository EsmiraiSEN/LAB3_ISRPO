# Примеры заголовков Markdown

## Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта

#### Что такое Markdown?
Markdown — это лёгкий язык разметки, разработанный для написания максимально читаемого и удобного для правки текста, который легко конвертируется в HTML.

#### Где он применяется?
Он повсеместно используется на GitHub для оформления файлов README, при создании технической документации, в баг-трекерах, блогах и мессенджерах.

#### Зачем он нужен разработчикам?
Он позволяет быстро форматировать текст без использования сложных визуальных редакторов, сохраняя код и документацию в едином текстовом стиле.
